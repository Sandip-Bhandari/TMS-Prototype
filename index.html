TaskPilot AI

A smart task and role management system for any team or organisation. Managers assign work faster, spot delays early and balance workload. It runs as an Android app and as a website, so everyone is covered: Android users, desktop users and iPhone users.

The problem

  • Tasks are assigned by message or paper, then written up again by hand.
  • Managers find out a task is late only after the deadline has passed.
  • Work piles up on a few people because nobody sees the whole team's load.

What the AI adds

✨ Smart FillOne sentence becomes a complete task: assignee, deadline, priority, instructions.
✨ Delay riskEvery task gets a risk label. Lists sort by what needs attention first.
✨ Workload balancerSpots overload and reassigns a task in one tap.
✨ Focus & chat helpEmployees see what to do first. Chats get summaries and reply suggestions.

One system, every device

PHP Laravel REST APILaravel Sanctum role-based accessKotlin + Jetpack Compose (MVVM)MySQLFirebase FCM pushResponsive web portal (Laravel Blade, Bootstrap 5)Gemini API (AI layer)

One Laravel REST API powers both the native Android app and the web portal. People who do not want to install the app simply open the website on a desktop browser or an iPhone. Same account, same tasks, same AI features on every device.

Phase 1 is the launch. Here is where it goes next.

This prototype is the launch version: it proves the core idea works end to end. The roadmap below is planned, and the order may change as real users give feedback.

Phase 1 · Launch (this prototype)Admin and Employee roles, task assignment, chat, attachments and approval. AI Smart Fill, delay risk, workload balancer and focus help. Android app and web portal with push notifications.
Phase 2 · Real AI and automationGemini-powered task parsing and chat summaries. Automatic escalation and reminders for overdue work. Exportable reports (PDF and Excel).
Phase 3 · ScaleHindi and other languages. Team performance analytics. Email and calendar integration, single sign-on and audit logs. Offline mode for low-network areas.

Honest scope

The prototype runs on sample data. The AI logic is rule-based here and is designed to be replaced by Gemini calls on the same endpoints in Phase 2.
